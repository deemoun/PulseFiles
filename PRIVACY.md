# PulseFiles Privacy Policy

**Effective date: 2026-07-22**

PulseFiles is a local macOS file manager. It does not operate telemetry,
analytics, advertising, or cloud-sync services, and it does not automatically
upload file names, file contents, filesystem paths, or diagnostics.

## Local data and permissions

PulseFiles reads and changes files only in locations macOS permits the app to
access, including folders you select or explicitly grant. App preferences,
recent locations, and security-scoped bookmarks are stored locally.

If you choose **Help → Export Diagnostics…**, PulseFiles creates a local,
reviewable support bundle. Sending that bundle to support is optional and
initiated by you. Review `REDACTION_POLICY.txt` in the exported bundle before
sharing it.

## Contact

For privacy questions, open a support request at
<https://github.com/deemoun/PulseFiles/issues>; do not include sensitive files
or credentials.
